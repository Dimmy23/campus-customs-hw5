# Campus Customs Agent-Team Reflection

## 1. Agent performance

Overall, I think the agents’ performance was acceptable, but not ideal. I could see that the task was being performed step by step, from the Boss to one agent at a time. We could improve performance by having the Boss communicate with all sub-agents simultaneously. Parallel work would likely reduce waiting time and improve the team’s efficiency.

## 2. Actual compared with Expected

The Actual results aligned with the Expected plan.

## 3. One agent versus five agents

All three tickets would have been simpler with one agent because each required only a few lookups in one small database, followed by a summary and a flag for human review. Using five agents with the same tools mostly added repeated lookups.

## 4. Three additional problems the team could solve

The team could:

1. Answer a stock question such as, “Do you have the Bulldog tee in size M?”
2. Summarize the printer’s reminder about an overdue invoice so a person can approve payment.
3. Rank the open tickets by urgency.

## 5. Three problems the team could not solve with the current tools

The team could not plan cash because no tool reads the bank balance or payment records. It could not restock products because no supplier is linked to products and the agents cannot place orders. It also could not follow up with customers because there is no customer contact information or email tool.

To solve these problems, I would add cash and payment lookups for Accounting; a supplier lookup and a human-approved purchase-order tool for a new Purchasing agent; and customer-contact and email tools, also requiring human approval, for Customer Service.
